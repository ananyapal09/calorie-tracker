# Calorie Tracker

A responsive web app to track your daily calorie intake, calculate BMI, and get personalized health recommendations. Built with React and Bootstrap.

## Features

- **Track Calories:** Log meals and monitor daily calorie intake.  
- **BMI Calculator:** Calculate your Body Mass Index and understand your health status.  
- **Health Recommendations:** Get personalized tips and advice to help meet your goals.  
- **Responsive Design:** Works well on desktop and mobile devices.

## Tech Stack

- **Frontend:** React, Bootstrap, React Router  
- **Icons:** FontAwesome  

## Installation

1. Clone the repository:  
   ```bash
   git clone https://github.com/ananyapal09/calorie-tracker.git
   
2.Navigate to the project folder:

 cd calorie-tracker
3.Install dependencies:
npm install
4.Start the development server:
npm start

The app will open in your browser at http://localhost:3000.
**Usage**
Click on Track Calories to log your meals.
Use the BMI Calculator to check your Body Mass Index.
Visit Health Recommendations for personalized tips.
